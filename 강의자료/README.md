# 강의자료 — "외주 4회 반려 → 직접 만든 도구로 승인"

> 지식상품(강의·전자책)의 모든 재료를 이 폴더에 모은다.
> 어떤 AI가 작업하든, 강의 관련 산출물은 **여기에만** 넣을 것.

## 폴더 구조

```
강의자료/
├─ 01_스크린샷/            # 촬영분. 날짜_상황 폴더로 구분
│   └─ 2026-08-27_신청직전/   ← 다운로드 폴더의 01~07 png 7장을 여기로
├─ 02_커리큘럼/            # 목차·챕터 구성안
└─ 03_원고/                # 챕터별 원고 초안
```

## 스크린샷 넣는 규칙

1. 촬영은 브라우저 다운로드(`~/Downloads`)로 떨어진다 — 브라우저 보안상 저장 위치를 코드로 지정할 수 없음
2. **`01_스크린샷/날짜_상황/` 폴더를 만들어 옮긴다** (예: `2026-08-27_신청직전`)
3. 파일명은 `번호_내용.png` 형식 유지 (예: `01_점검_16of16_만점.png`)
4. 각 촬영분의 **분류표(무엇을·왜 찍었는지)는 `records/`의 같은 날짜 문서**에 있다
   - 2026-08-27분: [`records/2026-08-27_02_신청직전_스크린샷_목록.md`](../records/2026-08-27_02_신청직전_스크린샷_목록.md)
