느슨=글자 500·즉시발행 · 표준=글자 700·초안+검토 · 엄격=글자 1000·옛정보면 발행보류. 아래 세부값은 프리셋을 덮어씁니다.

클라우드(GitHub Pages 등)에 올린 결과 파일 주소. 비워두면 같은 폴더의 data/latest.json 을 읽습니다.

🗄️ Supabase 연동 (초안 백로그 큐)

쌓인 초안을 하루 몇 편씩 순서대로 발행 전환하기 위한 저장소예요. 딱 한 번만 아래 1→2→3 순서로 하면 끝입니다(Supabase는 보안상 테이블 생성을 외부 앱에서 자동 실행하지 못하게 막아둬서, 이 SQL 실행 한 단계만 직접 눌러야 해요).
복사 → 편집기 열기 → 붙여넣기(⌘V) → Run. 이미 실행했다면 다시 안 해도 됩니다(재실행해도 안전).
⚠️ service_role 키는 전체 데이터에 접근 가능한 민감 정보입니다. GitHub Secret로만 저장되며(암호화), 이 앱 화면에는 다시 표시되지 않습니다.
완전 자동 배포(선택) — 아래 2개까지 등록하면, 이후 스키마가 바뀔 때마다 사람이 SQL을 복사·붙여넣기 하지 않아도 GitHub Actions가 자동으로 반영합니다(supabase/migrations/에 push → 자동 배포). 지금 당장은 위 1~3단계만으로 충분하며, 이 부분은 선택 사항입니다.
⚠️ 이 토큰은 계정 전체(모든 Supabase 프로젝트) 권한입니다. service_role 키보다 강력하니 더 조심해서 다루세요.

워드프레스에서 초안을 휴지통으로 보낸 뒤, 앱 목록만 깔끔하게 비우는 기능입니다. 기록은 지워지지 않고 🗃️ 보관함 칩으로 다시 볼 수 있으며, 발행을 다시 시작하면 새 글은 자동으로 목록에 나타납니다(보관 기준일 이후 글만 표시).
초안(draft) 상태의 글만 휴지통으로 옮깁니다. 발행된 글·예약글·페이지는 절대 건드리지 않습니다. 휴지통이라 워드프레스에서 복구 가능하며, 30일 후 자동 삭제됩니다(워드프레스 기본값).
