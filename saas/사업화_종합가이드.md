# SolvUp 사업화 종합 가이드 (직장인 1인 개발자)

> ⚠️ 본 문서는 **일반 정보**이며 법률·세무 자문이 아닙니다. 최종 결정 전 **회사 취업규칙 확인 + 세무사 상담**을 권합니다.

목표: 직장 다니며 SolvUp(1인 개발사) 준비 → 앱 개발 + Scripto 판매 + 강의 + 애드센스/제휴로 **여러 수입 파이프라인** → 장기적으로 안정되면 **퇴사·완전한 자유**.

---

## 1. 법적으로 걸리는 부분 (핵심 4가지)

**① 겸업(직장 다니며 부업) — 1순위 확인**
- 근로자의 겸업은 원칙적으로 자유(직업선택의 자유)지만, **회사 취업규칙/근로계약에 '겸업금지·겸직신고' 조항**이 있으면 위반 시 징계 가능.
- 회사 업무에 지장·이해충돌·영업비밀 침해가 없으면 대체로 문제되지 않음. **공무원은 원칙 금지.**
- 소득 노출 경로: 사업소득이 크면 **건강보험(직장 외 소득 연 2,000만원 초과 시 추가보험료)**·종합소득세로 회사가 인지할 수 있음.
- → **취업규칙부터 확인.** 애매하면 초기엔 배우자/가족 명의 검토(단, 세무·책임 이슈 있어 신중).

**② 사업자등록·통신판매업 — 판매하면 필수**
- 강의·구독을 지속·반복 판매하면 **사업자등록** 필요. 온라인 정기결제면 **통신판매업 신고**(등록면허세 연 ~4만5천원).

**③ 과장광고·보장 금지 — 표시광고법**
- "애드센스 **승인 보장**", "**수익 보장**" 문구 금지(과장광고). "승인까지 준비 대행 + 강의"로만.
- 자동 생성 콘텐츠로 고객 계정 정지 → 분쟁 소지 → **이용약관에 '검토 책임은 이용자', '승인·수익 미보장' 명시**.

**④ 전자상거래·개인정보**
- 회원·결제 받으면 **이용약관 + 개인정보처리방침 + 청약철회(환불) 규정** 필수(전자상거래법).
- Gemini 등 API: **사용자가 자기 키를 쓰면 각자 책임**(추천), 내가 키를 제공하면 내가 약관 책임.

> 결론: **불법 아님.** 단 ①겸업 확인 ②사업자·통신판매 등록 ③보장문구 금지 ④약관 구비가 조건.

## 2. 앱 개발과 병행 — 하나의 회사로 가능

**가능합니다. 오히려 하나로 묶는 게 효율적이에요.**
- 개인사업자 **SolvUp** 하나에 여러 업종을 등록: 소프트웨어 개발·자문, 정보서비스(SaaS), 온라인 교육(강의), 광고(애드센스/제휴).
- → 앱 수익, Scripto 구독, 강의, 제휴가 **한 사업자·한 장부**로 통합. 경비처리·세무·결제 연동이 단순해집니다.

---

## 3. 해야 할 일 (사업자등록 등) · 장단점

**할 일**
1. **개인사업자 등록** — 홈택스 온라인, 무료, 10분. 상호 "SolvUp". 업종코드 복수 등록.
2. **통신판매업 신고** — 정부24/구청. (사업용 계좌·구매안전서비스 필요할 수 있음)
3. **간이과세 vs 일반과세** — 초기 매출 적으면 **간이과세**(부가세 부담↓). 연 매출 커지면 일반 전환.
4. **사업용 통장·카드** 분리(경비·세무).
5. **세무** — 부가세(1·7월), 종합소득세(5월). 초기엔 세무사 기장(월 몇만원) 권장.

**장점**
- 경비 인정(장비·구독·광고비 비용처리) → 세금↓.
- 결제·세금계산서·신뢰 확보, 여러 파이프라인 통합.
- 앱스토어·PG·플랫폼 입점에 사업자 필요한 경우 많음.

**단점**
- 세무 신고·행정 의무. 건강보험(직장가입 유지되나 사업소득 크면 추가).
- 겸업 노출 가능성(소득 규모 커질수록).
- 초기 셋업 수고.

## 4. 예상 순수익 (비용 제외 · 예시, 보장 아님)

**전제**: 사용자가 자기 무료 API 키 사용(내 AI비 ≈ ₩0). 결제수수료 ~5%, Supabase 무료 티어.

| 파이프라인 | 보수적(1년차) | 성장(2~3년차) |
|---|---|---|
| Scripto 세팅비(9만원·1회) | 30명 → 270만 원 | 150명 → 1,350만 원 |
| Scripto 월 구독(9,900원~) | 평균 30명 → 178만 원 | 100명×12 → 1,188만 원 |
| 강의(번들 외 추가 판매) | 100만 원 | 500만 원 |
| 내 블로그 애드센스+쿠팡 | 100만 원 | 400만 원 |
| 앱 개발 수익(변동 큼) | 100만 원 | 600만 원 |
| **연 매출 합계(예시)** | **약 750만 원** | **약 4,000만 원** |
| 비용(수수료·호스팅·등록) | 약 50만 원 | 약 200만 원 |
| **세전 순이익(예시)** | **약 700만 원** | **약 3,800만 원** |

- 세금(부가세·소득세)은 별도로 소득의 **약 10~20%**를 준비금으로 떼어두세요.
- 이 숫자는 **마케팅·전환에 따라 크게 달라지는 예시**입니다(보장 아님). 핵심 변수는 "**고객 수**".
- **BYO 키 모델이라 사용자 늘어도 내 AI비가 안 늘어** → 마진이 유지되는 게 강점.

## 5. 지금부터 할 일 — 단계별 완전 가이드

### Phase A · 준비 (이번 주~2주, 등록 전에)
1. **회사 취업규칙 겸업 조항 확인**(가장 먼저). 애매하면 인사/노무 확인.
2. Scripto **본인 블로그로 실전 검증** — 애드센스 승인까지 직접 통과해보기(강의 소재 = 내 성공사례).
3. 상품·가격 확정(세팅비 9만 원 + 구독 티어).

### Phase B · 등록 (승인·첫 매출 준비되면)
4. **개인사업자 등록(SolvUp)** + **통신판매업 신고** + 사업용 계좌.
5. 이용약관·개인정보처리방침·환불규정 작성(보장문구 금지).
6. 결제 연동(페이플/토스 정기결제 또는 Lemon Squeezy).

### Phase C · 판매 (베타 → 정식)
7. 강의 1~4강(설치·키·연결·승인준비) 촬영 + 랜딩(노션).
8. **수강생 대상 소규모 베타(10명)** → 피드백·후기 확보.
9. 유튜브 데모 공개(퍼널 상단) → 정식 판매.

### Phase D · 확장·자동화
10. Supabase 로그인·구독·관리자(Phase 5 백엔드) 완성 → 다중 사용자 자동화.
11. 마케팅앱·디스커버·레퍼럴로 유입/리텐션.
12. 앱 개발 라인 병행(별도 수익).

### Phase E · 퇴사·자유 (조건 충족 시)
13. **부업 순이익이 급여를 안정적으로(예: 6~12개월 지속) 초과**하면 퇴사 검토.
14. 퇴사 후 = SolvUp 전업 → 자동화된 여러 파이프라인 관리 + 여가.

## 6. 리스크 관리 (자유를 지키려면)
- **다각화**: Scripto·강의·앱·애드센스 — 한 축이 흔들려도 버티게.
- **정책 리스크**: 애드센스/AI 정책은 바뀜 → "품질·사람검토·미보장 고지"로 방어.
- **세금 준비금** 별도 통장.
- **퇴사는 숫자로 결정**(감정 아님): 순이익이 급여+α를 N개월 지속 초과할 때.
